# Subtítulos en vivo para conferencias — Nerdearla Vibeathon 2026

Transcripción y traducción simultánea, open source, para conferencias con varias salas en paralelo.
Audio en vivo → subtítulos en tiempo real (idioma original + inglés→español) → vista web donde cada
persona elige la sesión y el idioma.

> Estado: **en construcción** durante la Vibeathon (24–25 de septiembre de 2026).

## Qué hace

- Recibe audio en vivo de un archivo, un stream o un micrófono. Incluye audios de prueba.
- Transcribe en tiempo real el idioma original (español o inglés).
- Traduce en tiempo real de inglés a español (y de español a inglés).
- Muestra los subtítulos en una página web por sesión e idioma.
- Procesa varias sesiones en simultáneo.
